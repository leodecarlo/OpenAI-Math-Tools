# Computational standards

When designing, implementing, or checking a mathematical algorithm:

- State the problem, assumptions, and intended behavior. Explain how the algorithm relates to the mathematics.
- Make code human-readable and maintainable: use clear names, straightforward structure, and explanations for non-obvious choices. Follow the project's established conventions.
- Choose an efficient method for the intended use. Consider resource costs and scalability without sacrificing correctness or clarity.
- Address stability and numerical sensitivity when relevant. Handle invalid input and failure to meet the algorithm's conditions explicitly.
- When convergence is relevant, state the conditions and stopping criteria. Distinguish a convergence argument from observed behavior, and report uncertainty or failure to converge.
- Validate the implementation with checks suited to the problem, using independent expectations where possible. Explain what the evidence establishes and its limits.
- Make results reproducible when practical. Report relevant inputs, settings, and observed results; distinguish work written, inspected, executed, and validated.
