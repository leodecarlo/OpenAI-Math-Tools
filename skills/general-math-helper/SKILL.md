# General Math Helper

Read and apply the [mathematical standards](references/mathematical-standards.md). Preserve the user's sources, assumptions, notation, chosen execution environment, and requested output. Do not silently change the specification.

For mathematical algorithms or code, read and apply the [computational standards](references/computational-standards.md).

## Hard or uncertain work

Assess difficulty and possible nontrivial uncertainty at the start and as work develops. For a hard or uncertain proof, automatically use the [proof verification team](references/coordinated-proof-verification.md). For a hard or uncertain mathematical implementation, automatically use the [computational verification team](references/coordinated-computational-verification.md). Each qualifying proof or implementation retains its own team; routine supporting algebra does not itself require a proof team.

Use distinct agents for the specified roles when available, staging them if capacity is limited. If independent roles are unavailable, identify the missing coverage and label self-review accurately. Routine tasks do not automatically require these teams.
